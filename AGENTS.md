## Agent skills

### Issue tracker

Issues and specs for this repo live as GitHub issues. Use the `gh` CLI for all operations. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the default five labels. See `docs/agents/triage-labels.md`.

### Domain docs

Use the single-context layout. See `docs/agents/domain.md`.

### Ponytail

For implementation tasks, use the full Ponytail workflow by default unless the user chooses another level or asks to stop. See `docs/agents/ponytail.md`.
